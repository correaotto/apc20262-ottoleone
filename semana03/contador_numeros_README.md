Esse algortimo apresenta um contador de números presentes em uma sequência inserida pelo usuário, com condição de encerramento caso o usuário digite "-1"

É esperado que o algoritmo encerre assim que o usuário insira o "-1"

Nesse sentido, são exemplos de resultado do algoritmo:
| Sequência de Entrada | Resultado Esperado | Descrição |
| :--- | :---: | ---: |
| 5, 12, 8, -1 | 3 | Caso normal |
| -1 | -1 | Lista vazia |
